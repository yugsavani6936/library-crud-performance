How Measurements Are Taken
Database Execution Time vs. Total HTTP Latency

To maintain strict scientific validity for this academic evaluation, our timer measures pure relational database execution duration using Python's monotonic time.perf_counter_ns().

What is Measured:
  • Time taken by PostgreSQL server to execute SQL queries.
  • Django ORM compilation into SQL and object hydration.
  • Write Ahead Log (WAL) flushing and transaction commits.
What is Excluded:
  • Network TCP/IP latency between browser and laptop.
  • Django template HTML rendering overhead.
  • Browser DOM parsing and CSS rendering delay.
Data Isolation Guarantee

All benchmark rows are generated with is_benchmark=True and clean unique test ISBNs. Real library catalog books (is_benchmark=False) are strictly protected and never altered, overwritten, or deleted during any experiment.
